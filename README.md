# 介绍 ".lua" 脚本文件的下载和使用方法

* 打开右上方代码选项，下载压缩包
* 下载、安装SteamTools软件：https://www.steamtools.net/

## 操作步骤

* 解压下载好的压缩包，将里面的".lua"文件拖入到SteamTools的悬浮窗上
* 如果跳出“已编译*个Lua脚本，将在...后生效”，说明导入成功，重启Steam，就可以看到本地入库的游戏

### 问题
* 如果不能将".lua"文件拖入到悬浮窗上，请检查电脑是否默认以管理员身份运行SteamTools
* 如果重启Steam后，发现没有看到本地入库的游戏，请将Steam设置下，界面设置里，改成“未选中任何测试版”
